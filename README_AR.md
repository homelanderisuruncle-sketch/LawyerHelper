# بوت المساعد الذكي للمحررات القضائية

بوت تيليجرام عام يحتوي خدمتين:
1. استخراج النص من الصور باستخدام Gemini Vision.
2. تعبئة قالب DOCX وفق العلامات الموجودة داخله، ثم إدراج نص المذكرة وتطبيق أوامر تنسيق محددة.

> **تنبيه مهم:** هذه نسخة أولية قابلة للتجربة وليست نظاماً إنتاجياً مضموناً. راجع كل حرف واسم وتاريخ وتنسيق قبل اعتماد أي مستند. لا ترفع مستندات سرية أو بيانات قضايا حساسة إلى Gemini المجاني؛ بيانات المستوى المجاني قد تستخدم لتحسين خدمات Google وفق شروطها.

## ما الذي يدعمه القالب؟

يقرأ البوت علامات مثل:
- `#هنا اسم المحكمة#`
- `#هنا الموضوع#`
- `#هنا اسم المدعي#`
- `#هنا اسم المدعي عليه#`
- `#هنا اسم القاضي#`
- `#تبدأ كتابة من هنا#`

العلامة الأخيرة هي نقطة إدراج متن المذكرة. يحتفظ البوت بباقي محتويات القالب، ويضيف النص بعدها.

يمكن أيضاً استخدام حقول عامة بين أقواس معقوفة مثل `{{COURT_NAME}}` مستقبلاً، لكن النسخة الحالية تعتمد علامات `#...#` الظاهرة في القالب المرسل.

## أوامر التنسيق

ضع الأمر في سطر مستقل بعد السطر المقصود:
- `#اجعل السطر السابق باللون الأحمر#`
- `#اجعل السطر السابق عريضاً#`
- `#ضع السطر السابق في المنتصف#`
- `#ضع خطاً تحت السطر السابق#`
- `#ابدأ صفحة جديدة#`

الأوامر غير المعروفة لا تنفذ؛ تظهر كتنبيه داخل النص حتى لا تضيع بصمت. تجنب الأوامر العامة المبهمة، وراجع الملف الناتج.

## النشر دون تثبيت أي شيء على جهازك

### 1) إنشاء بوت تيليجرام
1. افتح Telegram وابحث عن `@BotFather`.
2. أرسل `/newbot`.
3. اختر اسماً واسم مستخدم ينتهي بـ `bot`.
4. انسخ الرمز `TELEGRAM_BOT_TOKEN` واحتفظ به سراً.

### 2) إنشاء مفتاح Gemini
1. افتح https://aistudio.google.com/app/apikey
2. سجّل الدخول وأنشئ API key.
3. انسخ المفتاح `GEMINI_API_KEY`.
4. راجع https://ai.google.dev/gemini-api/docs/pricing لمعرفة النماذج المتاحة مجاناً وحدود الطلبات في بلدك وحسابك.
5. النموذج الافتراضي في المشروع `gemini-3.7-flash`. إذا لم يكن متاحاً في حسابك، غيّر متغير `GEMINI_MODEL` إلى نموذج Flash متاح في صفحة النماذج.

**مهم:** الحصة المجانية محدودة وقد تتغير. لا تضع بيانات بطاقتك ولا تفعّل الفوترة إذا كان هدفك عدم الدفع.

### 3) رفع الملفات إلى GitHub من المتصفح
1. افتح https://github.com/new وأنشئ Repository جديداً.
2. اجعله Public أو Private حسب رغبتك. لا ترفع مفاتيح API أو ملفات قضايا أو قوالب فيها بيانات شخصية.
3. افتح المستودع واضغط `Add file` ثم `Upload files`.
4. فك ضغط ZIP على جهازك أو استخدم الملفات المرفقة، ثم ارفع محتويات مجلد المشروع إلى جذر المستودع.
5. اضغط `Commit changes`.

لا تحتاج تثبيت Git أو Python أو أي مكتبة.

### 4) نشره على Render مجاناً
1. افتح https://render.com وسجّل الدخول.
2. اختر `New` ثم `Web Service`.
3. اربط حساب GitHub واختر المستودع.
4. اترك Render يقرأ `render.yaml` إن عرض خيار Blueprint، أو أدخل:
   - Runtime: Python
   - Build command: `pip install -r requirements.txt`
   - Start command: `gunicorn --workers 1 --threads 4 --timeout 120 main:app`
   - Instance type: Free
5. بعد إنشاء الخدمة، افتح `Environment` وأضف:
   - `TELEGRAM_BOT_TOKEN` = رمز BotFather
   - `GEMINI_API_KEY` = مفتاح Google AI Studio
   - `PUBLIC_BASE_URL` = رابط Render الكامل مثل `https://اسم-الخدمة.onrender.com` (بدون `/` في النهاية)
   - `WEBHOOK_SECRET` = كلمة عشوائية طويلة يصعب تخمينها، أحرف وأرقام فقط
   - `GEMINI_MODEL` = `gemini-3.7-flash`
   - `DAILY_LIMIT` = `8`
   - `MAX_FILE_MB` = `12`
6. اضغط Save ثم Manual Deploy إذا لزم.
7. افتح رابط الخدمة في المتصفح. يجب أن ترى `{"status":"ok"...}`.
8. افتح البوت في Telegram وأرسل `/start`.

### 5) تحديث الكود
أي تعديل ترفعه إلى GitHub سيؤدي إلى إعادة النشر التلقائي إذا كان الربط مفعلاً.

## قيود النسخة المجانية
- Render Free يوقف الخدمة بعد 15 دقيقة دون زيارات، وقد يستغرق إيقاظها قرابة دقيقة.
- نظام الملفات في Render مؤقت؛ لذلك هذه النسخة تحتفظ بالملفات المؤقتة في الذاكرة ولا تنشئ أرشيفاً دائماً للمستندات.
- ذاكرة الجلسات والحصة اليومية مؤقتة وتُصفّر عند إعادة تشغيل الخدمة. لذلك حدود الاستخدام هنا حماية أولية وليست نظام حصص محكماً.
- Telegram وGemini وRender لديهم حدود استخدام مستقلة.
- لا يمكن ضمان تشغيل مجاني 24/7 أو استقبال غير محدود.

## ملاحظات تقنية وأمنية
- البوت عام؛ أي مستخدم يستطيع بدء المحادثة معه.
- يطبق حدّاً تجريبياً قدره 8 طلبات لكل مستخدم في اليوم، لكنه يعاد عند إعادة تشغيل الخدمة.
- لا ترسل للموديل إلا صورة OCR التي يطلبها المستخدم؛ تعبئة Word تتم محلياً داخل خدمة البوت.
- لا تستخدم هذا الإصدار في ملفات شديدة السرية أو في الإنتاج القضائي قبل إضافة قاعدة بيانات، حصص ثابتة، اختبارات OCR، مراقبة، ومراجعة أمنية.
- نموذج الرؤية قد يخطئ في خط الرقعة، خصوصاً الصور المائلة أو المعتمة. الكلمات غير الواضحة يجب مراجعتها يدوياً.

## الملفات
- `main.py`: التطبيق والبوت ومعالجة Word.
- `requirements.txt`: المكتبات التي يثبتها Render تلقائياً.
- `render.yaml`: إعداد النشر.
- `.gitignore`: يمنع رفع الملفات المحلية الحساسة.
